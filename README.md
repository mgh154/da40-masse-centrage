# DA40 · Masse et centrage

Outil de préparation de vol pour le DA40 : masse et centrage avec centrogramme, performances (TODR/LDR, vent de travers, altitude densité), triangle des vitesses et CRP-5.

Page unique, sans dépendance à installer : ouvrir `index.html` dans un navigateur.

Données basées sur la fiche New CAG « Mass and balance data », rév. 4.1 du 18 juin 2026. Les distances sont une lecture numérisée de l'AFM (± 5 %). Outil d'aide uniquement, à vérifier avec l'AFM et le FI : il ne constitue pas une autorisation de vol.
